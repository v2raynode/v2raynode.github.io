一、Shadowrocket简介：为iOS用户量身打造的网络代理工具

1. 什么是Shadowrocket？

Shadowrocket 是一款功能强大的 iOS 端代理工具，支持多种协议（如 Shadowsocks、Vmess、Trojan 等），并允许用户灵活配置自己的代理规则，实现按需科学上网。

它并非普通意义上的 VPN，而是一个更高级、更灵活的“代理客户端”，可通过配置文件连接远程代理服务器，达到绕过地理封锁、访问全球互联网的目的。

2. 平台兼容性

  • 适用系统：仅限 Apple iOS（iPhone、iPad）设备；

  • 购买方式：目前仍需通过海外 App Store 付费购买（约 $2.99 美元）；

  • 安装方式：无越狱需求，安装后即用。

二、Shadowrocket还能用吗？现状解析

尽管近年来封锁机制日趋严格，但Shadowrocket在多数场景下依然可用，且凭借灵活的配置能力与强大的社群支持，仍被广泛用于访问境外内容。

1. 支持多协议，抗封锁能力强

Shadowrocket 支持以下多种翻墙协议：

  • Shadowsocks / ShadowsocksR：经典协议，轻量快速；

  • Vmess / VLESS（V2Ray协议）：抗干扰性好，适合长期使用；

  • Trojan / Trojan-Go：伪装能力强，基于 TLS 加密；

  • HTTP / HTTPS / SOCKS5 / QUIC等高级代理协议。

用户可根据网络环境与审查程度，自由切换协议以获得更稳定的连接体验。

2. 社群生态活跃，配置资源丰富

虽然 Shadowrocket 本身只提供客户端工具，但得益于庞大的用户社群、代理服务提供商，以及配置分享平台，用户可以轻松获取：

  • 高质量的订阅链接；

  • 实时更新的规则文件；

  • 节点测速脚本与优化方案。

3. 开发持续维护，功能不断增强

Shadowrocket 由开发者 Shadow Launch 维护，尽管更新频率不高，但在稳定性、安全性和兼容性方面表现优异，支持多种 DNS 模式、流量统计、去广告等功能，完全胜任日常科学上网需求。

四、Shadowrocket配置教程（新手入门）

1. 获取代理服务器信息

在开始配置前，你需要从代理服务商或技术朋友处获取以下信息：

  • 节点地址（IP 或域名）；

  • 端口号；

  • 加密方式；

  • 用户名 / 密码（或UUID）；

  • 协议类型（Shadowsocks / Vmess / Trojan等）。

或直接获取 .conf / .json / .yaml / .txt 等格式的订阅链接或配置文件。

2. 手动添加节点

  1. 打开 Shadowrocket 应用；

  2. 点击右上角 “+” 添加配置；

  3. 根据代理类型填写必要字段；

  4. 命名此配置，例如“东京节点”、“香港高速线路”等；

  5. 点击“完成”保存。

3. 使用订阅链接自动导入（推荐）

  1. 打开主页面，点击“配置”；

  2. 选择“添加订阅”；

  3. 粘贴订阅链接；

  4. 命名配置组；

  5. 点击“更新”自动同步所有节点信息。

4. 选择并启用节点

返回主页面，长按某一节点进行测速，选择延迟最低的节点启用，即可开启翻墙服务。

五、进阶技巧：让Shadowrocket更强大

1. 使用规则分流，实现智能上网

通过配置规则（如 DOMAIN-SUFFIX, google.com, Proxy），你可以实现：

  • 国内网站直连（节省流量）；

  • 国外服务走代理（提升速度）；

  • 自定义黑白名单、地区路由、关键字过滤等功能。

2. 测速选择最优节点

  • 使用 Shadowrocket 内置的 ping 测速；

  • 借助第三方测速平台（如 fast.com、speedtest.net）测试下载速度；

  • 删除延迟高、不稳定的节点。

3. 防DNS污染与泄漏

在“设置”中开启 DoH（DNS over HTTPS）或 DoT（DNS over TLS），可有效防止 DNS 劫持，提高隐私安全性。

4. 限制部分App走代理

你可以在“规则”中指定哪些应用使用代理、哪些直连，以此控制流量与提升效率。

FAQ

VLess 使用 XTLS 时证书怎么配置更安全？
推荐使用可信 CA 签发的证书（例如 Let's Encrypt），并为服务器配置正确的域名、SNI 与证书链。避免使用自签名证书或错误域名，以免被客户端拒绝或被中间人攻击检测到。
Sing-box 的 route 功能如何工作？
Sing-box 提供强大的路由系统，允许用户基于 IP、域名、GEO 数据库、进程名等条件精细分流。配置完成后，程序自动匹配规则，将不同流量转发到对应的出口。
VMess AEAD 加密如何保证数据安全？
AEAD 加密防止数据篡改、重放攻击和流量特征泄露。在高封锁环境下使用，可保证节点长期可用，提升数据安全和连接稳定性，同时降低被检测风险。
Nekobox 可以与其他代理客户端共存吗？
可以。Nekobox 与 Shadowsocks、Clash 等客户端互不干扰，可以同时运行。用户可通过策略组或分流规则选择使用节点，实现灵活的网络管理。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
SSR 混淆方式如何提高抗封锁能力？
SSR 混淆可将流量伪装成正常 HTTPS 或 HTTP 数据，降低被 DPI 检测风险。合理选择协议和混淆参数组合，可以提高节点稳定性和长期可用性，保证科学上网体验顺畅。
WinXray 支持测速功能吗？
支持。WinXray 提供节点延迟测速功能，可检测每个节点的响应时间与可用性。测速结果能帮助用户选择最快线路，也能排除无效或不稳定的节点，提高整体网络体验。
VMess 的 gRPC 传输适合移动网络吗？
gRPC 传输支持长连接和多路复用，减少握手次数，降低延迟。对于移动网络和高延迟环境，它能提供稳定和高速的访问体验，同时降低掉线和延迟波动风险。
Netch 全局与规则代理如何合理选择？
全局代理适合游戏或全局科学上网，将所有流量通过节点；规则代理仅对指定应用或 IP 走代理，可提高带宽利用率和访问效率，根据使用场景灵活选择模式。
PassWall2 是什么软件？
PassWall2 是一个运行在 OpenWRT 路由器上的插件，用于代理流量分流和节点管理。它支持多种协议，包括 V2Ray、Trojan、SSR 等。通过 Web 界面，用户可以灵活设置不同设备走不同代理，适合家庭或小型局域网使用。
