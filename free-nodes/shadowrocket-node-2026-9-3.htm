初识 Shadowrocket：它究竟是何方神圣？

简单来说，Shadowrocket 是一款运行在 iOS 平台上的网络代理客户端。它本身并不提供 VPN 服务，而是作为一个“客户端”，帮助你去连接自己购买或搭建的代理服务器（如 VPS 上的 Shadowsocks、V2Ray 等）。它的核心价值在于智能分流：你可以设定规则，让国内流量直连，国外流量走代理，从而在保证访问速度的同时，解决网络封锁和地域限制问题。

与一些“傻瓜式”的一键 VPN 应用不同，Shadowrocket 的魅力在于其高度的透明性和可控性。你可以清晰看到每个连接的走向，可以自定义近乎无限条规则，甚至可以通过脚本（JavaScript）实现一些高级的自动化操作。对于喜欢折腾、追求极致性能的用户来说，它不仅仅是一个工具，更像是一个可以自由编程的网络平台。

核心配置教程：从零到一搭建你的专属代理

安装好 Shadowrocket 后，面对简洁的界面，新手往往一头雾水。别急，我们一步步来。

第一步：获取代理服务器信息

这是最关键的一步。你需要先拥有一个代理服务器。你可以选择： - 自建服务器：购买一台海外 VPS（如 Vultr、DigitalOcean 等），自行安装服务端。这是最安全、最稳定的方式，但需要一定技术基础。 - 购买机场服务：从第三方服务商购买订阅链接。这种方式简单省事，只需复制粘贴链接即可。

无论哪种方式，你都会获得一组关键信息：服务器地址、端口、加密方式（协议）、密码，或者是一个订阅链接。

第二步：两种最基本的导入方式

方式一：手动添加代理节点

  1. 打开 Shadowrocket，点击首页右上角的 “+” 号。
  2. 在弹出界面中，选择类型（通常为 Shadowsocks 或 Vmess，根据你的服务商提供的信息填写）。
  3. 填写地址（服务器 IP 或域名）、端口、密码。如果是 Vmess 协议，可能还需要填写额外 ID（UUID）。
  4. 点击右上角“保存”。此时，首页会多出一个节点卡片。

方式二：订阅导入（强烈推荐）

对于购买了机场服务的朋友，这是最高效的方法。

  1. 复制机场官网提供的订阅地址（通常以 https:// 开头，包含一串长字符）。
  2. 打开 Shadowrocket，点击首页右上角的 “+” 号。
  3. 在类型选择中，下拉找到 “Subscribe” 选项。
  4. 在 URL 一栏粘贴订阅链接，备注可随意填写，便于识别。
  5. 点击保存。此时，应用会自动拉取并解析出所有节点列表。你会看到首页出现了多个节点卡片。

第三步：设置全局模式与规则分流（核心中的核心）

这是 Shadowrocket 最强大的地方。在首页顶部，有两个关键开关：

  • 全局路由：点击后可以选择“配置”、“代理”或“直连”。
  • 代理开关：最顶部的那个大开关，点击即可开启或关闭代理。

正确的姿势是使用“配置”模式。Shadowrocket 默认自带一套非常优秀的国内直连、国外代理的规则。你不需要手动修改，只需确保在“全局路由”中选中“配置”即可。

如何验证规则是否生效？ 开启代理后，你可以访问一个国内网站（如百度）和一个国外网站（如 Google）。如果百度能秒开，Google 也能访问，说明规则工作正常。如果国内网站变慢，说明规则可能有问题，或者你开启了“代理”模式（即全局代理）。

第四步：自定义规则与高级玩法

Shadowrocket 的魅力在于你可以为特定域名或 IP 指定走代理还是直连。

  1. 点击首页底部的“设置”标签。
  2. 找到“规则”选项，点击进入。
  3. 你会看到默认规则列表。点击右上角“+”可以添加新规则。
  4. 例如，你可以添加一条规则：类型选择“域名匹配”，值填写 *.instagram.com，策略选择“代理”。这样，所有访问 Instagram 的流量都会强制走代理，即使默认规则没有匹配到。

进阶技巧： 你可以利用“脚本”功能，实现如自动切换节点、修改请求头等高级功能。虽然需要一定的编程基础，但网上有大量现成的脚本可供参考，大大提升了可玩性。

使用指南：如何让“小火箭”飞得更高更稳

1. 节点选择有讲究

  • 延迟不是唯一标准：虽然延迟（Ping）很重要，但丢包率更关键。一个高延迟但低丢包的节点，往往比低延迟高丢包的节点体验更好。
  • 区分高峰期：晚高峰（20:00-23:00）国际带宽拥堵严重。此时可以尝试切换至冷门地区节点（如欧洲、东南亚），或者使用支持 UDP 的节点，提升游戏体验。

2. 注意电池与流量的平衡

Shadowrocket 在后台运行时会消耗一定电量和流量。建议在不需要科学上网时，关闭代理开关（或者使用“配置”模式让国内流量直连，减少不必要的代理连接）。同时，定期在“设置”中查看“流量统计”，了解各节点的流量消耗情况，避免超额。

3. 定期更新订阅

机场的节点 IP 经常变动。如果发现节点全部无法连接，请回到订阅页面，下拉刷新，重新拉取最新的节点列表。

常见问题解答（FAQ）：你踩过的坑，我都替你踩过了

Q1：为什么我的 Shadowrocket 连接不上？ - 检查网络：确保你的 Wi-Fi 或蜂窝数据正常。 - 检查时间：iOS 设备时间不准确会导致 TLS 握手失败，务必开启“自动设置”。 - 检查节点信息：重新核对密码、端口，尤其是 Vmess 的 UUID 是否有多余空格。 - 检查订阅是否过期：机场订阅有有效期，过期后节点会失效。

Q2：为什么速度很慢？ - 尝试更换节点：选择当前负载较低的节点。 - 切换协议：如果服务商支持，可以尝试从 Shadowsocks 切换到 Vmess 或 Trojan，后两者在抗封锁方面通常更优。 - 开启“复用”设置：在节点详情页，尝试开启“TCP Fast Open”或“多路复用”选项，有时能显著提速。

Q3：如何删除或修改已添加的代理？ - 在首页节点列表上，向左滑动节点卡片，会出现“修改”和“删除”选项。或者在节点详情页底部找到“删除”按钮。

Q4：Shadowrocket 安全吗？ - 作为客户端，它本身不记录你的浏览日志。但安全性主要取决于你使用的服务端。自建服务器相对安全，而使用不明来源的免费机场则存在隐私泄露风险。强烈建议不要使用免费代理！

Trojan 的伪装域名为什么重要？
伪装域名必须真实可访问且证书有效，以使流量看起来像普通 HTTPS 请求。正确配置可以降低被封锁和 DPI 检测风险，提高节点安全性和长期可用性。
Trojan 伪装域名如何选择以提升隐蔽性？
伪装域名应选择真实可访问网站并配备有效证书，这样 Trojan 流量可模拟正常 HTTPS 请求，降低被封锁和检测的风险，提高节点长期可用性和访问稳定性。
如何在 Clash Premium 中使用 TUN 模式加速游戏？
Clash Premium 版本支持系统级 TUN 模式，可将所有 UDP 流量转发至代理节点。启用该模式后需管理员权限，并在配置文件中添加 dns 与 tun 模块，选择低延迟节点即可实现游戏加速。
Trojan TLS 伪装如何降低被封锁风险？
通过选择真实可访问的域名并安装有效证书，Trojan 流量可完全模拟 HTTPS 请求。这样可隐藏流量特征，降低被封锁和 DPI 检测的可能性，保证节点长期可用。
SSR 的协议插件如何应对封锁？
协议插件可隐藏真实通信特征，将流量伪装成正常 HTTP 或 TLS 数据。结合混淆方式使用，可以有效降低被 DPI 检测或封锁的风险，提高节点稳定性和长期可用性。
Nekoray 节点订阅失败如何处理？
首先确认订阅 URL 是否有效，并确保网络连接正常。可手动刷新或重新添加订阅链接，保证节点列表最新。结合策略组使用，确保稳定科学上网体验。
Mellow 的 TUN 模式与系统代理有何区别？
TUN 模式直接拦截 IP 层流量，实现全局代理，而系统代理通常仅影响支持代理的应用。TUN 更适合游戏、视频或全局科学上网场景，确保所有流量经过代理节点。
Vmess 节点可以通过 CDN 吗？
可以。Vmess 可通过 WebSocket 与 CDN 结合使用，只需将传输方式设置为 WS 并配置 host 与 path，即可实现流量中转。这样既能隐藏真实服务器，又能提升连接速度。
